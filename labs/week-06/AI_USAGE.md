## ครั้งที่ 1

**ถามอะไร**
- ถามเกี่ยวกับขั้นตอนการทำ LAB06 Take-Home ตั้งแต่ CP06–CP08 และจุดที่ต้องเก็บ Screenshot เป็นหลักฐาน

**AI ตอบว่าอย่างไร (สรุปสั้น)**
- AI อธิบายหน้าที่ของ Route, Controller และ Service รวมถึงวิธีทำ centralized error handling และการบันทึกข้อมูลลง requests.json เพื่อให้ข้อมูลไม่หายเมื่อ restart server

## ครั้งที่ 2

**ถามอะไร**
- ถามเกี่ยวกับ Challenge การกรองข้อมูลด้วย query string และการใช้ PUT /api/requests/:id เพื่อเปลี่ยนสถานะคำร้อง

**AI ตอบว่าอย่างไร (สรุปสั้น)**
-AI อธิบายการรับ req.query.status, การตรวจค่า status ที่อนุญาต, การค้นหาคำร้องตาม ID และการใช้ persist() หลังจากเปลี่ยนข้อมูล
