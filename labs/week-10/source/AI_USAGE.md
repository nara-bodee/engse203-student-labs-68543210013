# AI Usage

ใช้ AI ช่วยอธิบายและตรวจแนวทางการทำ LAB Week 10

## สิ่งที่ถาม AI

- ช่วยอธิบายการเปลี่ยน service จาก JSON เป็น SQLite
- ช่วยอธิบายการใช้ JOIN และ AS
- ช่วยอธิบายการแปลง requesterName เป็น requester_id
- ช่วยตรวจแนวทาง parameterized query เพื่อป้องกัน SQL Injection
- ช่วยแนะนำ test cases สำหรับ API
- ช่วยตรวจ API_CONTRACT.md

## สิ่งที่นำมาใช้

นำแนวทางและตัวอย่างโค้ดมาปรับใช้ใน `requestService.js`, `api.test.js` และเอกสารประกอบ

## สิ่งที่ตรวจและแก้เอง

- รัน checker ของ Week 10 และ Week 07
- แก้ error ตามผลที่ได้
- ทดสอบ API จริง
- ตรวจผล SQL Injection
- ตรวจว่า frontend ยังใช้งานร่วมกับ API ได้
