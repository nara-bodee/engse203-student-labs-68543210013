# Database Choices

## 1. ทำไมโปรเจกต์นี้เลือก SQLite แทน MongoDB

โปรเจกต์นี้เลือก SQLite เพราะข้อมูลมีโครงสร้างค่อนข้างชัดเจน และมีความสัมพันธ์ระหว่างข้อมูล เช่น ผู้ใช้กับคำร้อง จึงเหมาะกับฐานข้อมูลแบบ relational นอกจากนี้ SQLite ไม่ต้องเปิด Database Server แยก ทำให้ติดตั้งและทดสอบได้ง่าย สำหรับระบบ LAB ที่มีข้อมูลและจำนวนผู้ใช้ไม่มาก SQLite จึงเพียงพอต่อการใช้งาน

## 2. ถ้าวันหนึ่งต้องเปลี่ยนไป MongoDB จะกระทบชั้นไหนบ้าง

ถ้าเปลี่ยนจาก SQLite ไป MongoDB จะกระทบหลัก ๆ ที่ชั้น service เพราะต้องเปลี่ยนวิธีเชื่อมต่อและคำสั่งที่ใช้จัดการฐานข้อมูล นอกจากนี้ยังอาจกระทบ controller ด้วย เพราะ MongoDB driver ทำงานแบบ async จึงต้องใช้ `async/await` ในการรอผลจาก service ส่วน frontend ไม่ควรต้องแก้ ถ้า API ยังส่งข้อมูลออกมาในรูปแบบเดิม

## 3. async จำเป็นเมื่อไร ไม่จำเป็นเมื่อไร

async จำเป็นเมื่อโปรแกรมต้องรอการทำงานที่ใช้เวลา เช่น การเรียก API หรือการเชื่อมต่อฐานข้อมูลที่อยู่คนละเครื่อง เพราะระหว่างรอ Node.js สามารถไปทำงานอื่นได้ แต่ถ้าเป็นงานที่ทำเสร็จทันทีในเครื่องและใช้ synchronous API เช่น SQLite `DatabaseSync` ก็ไม่จำเป็นต้องใช้ async ทุกจุด การเลือกใช้จึงขึ้นอยู่กับลักษณะของงานและวิธีที่ library รองรับ
